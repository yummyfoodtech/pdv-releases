# Yummy PDV — instaladores

Downloads do **Yummy PDV**, o sistema de ponto de venda da Yummy Food Tech.

### 👉 [Baixar o Yummy PDV](https://yummyfoodtech.github.io/pdv-releases/)

Não é preciso ter conta no GitHub para baixar.

---

Este repositório hospeda **apenas os instaladores**. O código-fonte do Yummy PDV
é privado.

Cada versão publicada aparece em [Releases](https://github.com/yummyfoodtech/pdv-releases/releases)
com os instaladores de macOS (`.dmg`, Apple Silicon e Intel) e Windows (`.exe`).

As versões são marcadas como *pre-release* enquanto os instaladores não forem
assinados digitalmente. A página de download explica o passo extra que o macOS
e o Windows pedem na primeira instalação.
